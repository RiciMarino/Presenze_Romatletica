# Romatletica · QR e presenze

Prima versione dell'interfaccia per richieste di prova e allenamenti.

## Regole dati

- Gli export Golee vengono letti tramite le intestazioni, indipendentemente dall'ordine delle colonne.
- Il codice fiscale è la chiave privata di riconciliazione fra archivio prove e archivio iscritti.
- Il QR espone soltanto un ID Romatletica casuale.
- Nessun dato personale deve essere pubblicato nel repository GitHub Pages.

## Stato della versione

Questa versione contiene soltanto record dimostrativi e persistenza locale nel browser. Il passaggio successivo è collegare l'interfaccia a un archivio riservato e inserire il link Golee per l'iscrizione definitiva.
